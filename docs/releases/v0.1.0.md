# Mise PR v0.1.0 — Review packets for pull requests

Initial public release of **Mise PR**, the review-readiness layer for pull requests.

## Highlights

- GitHub Action that generates a Markdown review packet.
- JSON output for AI agents, CI systems, and enterprise automation.
- Deterministic scoring for PR size, churn, risky paths, missing tests, weak descriptions, and missing issue/spec links.
- Configurable `.mise-pr.yml` policy file.
- Local CLI for maintainers and automation scripts.
- PR comment mode with update-in-place behavior to avoid bot-comment spam.
- Product Hunt launch kit and GitHub Marketplace listing copy.

## Installation

```yaml
- name: Generate review packet
  uses: DeontewattsV1/mise-pr@v0.1.0
  with:
    base-ref: origin/${{ github.base_ref }}
    head-ref: HEAD
    fail-on: red
    comment: true
```

## Notes

This release is intentionally simple: no hosted backend, no LLM requirement, no external code transfer by default.
